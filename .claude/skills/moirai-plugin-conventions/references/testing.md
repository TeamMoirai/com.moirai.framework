# 测试与验证分层（本包）

## 装配事实

本包没有统一测试装配；只有 addressables、fmod、memorypack、messagepack、protobuf、wwise 六个插件带 `*/Tests/` 测试 asmdef（2026-10-21 实测，各 1 个测试文件）。其余插件无测试装配。

## 替代判据

| 层 | 能给什么 | 不能给什么 |
|---|---|---|
| 编译门 | 插件与框架是否 0 error | 外部 SDK 未安装分支 |
| 插件测试 | 6 个测试装配的 passed/failed | 其余插件 |
| 静态判据 | manifest/asmdef/meta | 运行期适配 |

## 写什么、不写什么

| 写 | 不写 |
|---|---|
| 适配契约、序列化往返、后端能力探测 | 外部 SDK 内部行为 |
| 失败降级与空目标 | 宿主工程配置 |

## 改动的验证清单

| 改动 | 最低验证 |
|---|---|
| 只改 manifest | check:manifest |
| 改插件代码 | 编译门 + 该插件测试（若有） |
| 改 asmdef/宏 | 编译门 + 宏组合 |

## 判绿与出口

- 有测试装配的插件：0 失败才算通过。
- 无测试装配的插件：编译门 + 人工/静态判据，单列“未取证”。
