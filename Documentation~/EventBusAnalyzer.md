# EventBusAnalyzer：EventBus 使用规范分析器与订阅胶水生成器

`EventBusAnalyzer`（`SourceGenerators/EventBusAnalyzer.dll`，源码 `SourceGenerators/Source~/EventBusAnalyzer/`）随包自动生效：Unity 对引用 `Moirai.Atropos` 的所有程序集应用本分析器与源生成器，无需任何工程配置。

## 用途

两条能力配合落实 EventBus 的使用规范：

1. **分析器（Analyzer）**：静态检查订阅规范，违规处以 MA 诊断告警（MA7xxx 段，统一 MA+4 位段号方案）；
2. **源生成器（Source Generator）**：为含 `OnXxxEvent` 回调的 `partial` 类型生成成对的 `SubscribeEvents()` / `UnsubscribeEvents()` 订阅胶水，并让**无参回调** `OnXxxEvent()` 成为可订阅形态。

## 诊断规则（默认 Warning，可经 .editorconfig 调级）

| ID | 规则 | 说明 |
| --- | --- | --- |
| MA7000 | 禁止匿名函数订阅/退订 | `EventBus.Subscribe` / `EventBus.Unsubscribe` 的实参不得是 lambda/匿名方法——匿名委托每次生成新实例，`Unsubscribe` 的值等价匹配（同方法同目标）永不命中，订阅即泄漏 |
| MA7001 | 带参回调必须 `in` 修饰 | `OnXxxEvent` 的参数必须是 `in XxxEvent evt`（缺 `in`、或写成 `ref`/`out` 均告警）。方法组转换要求 ref-kind 精确匹配，缺 `in` 的处理器**无法**被 `EventBus.Subscribe<T>` 订阅，不只是性能问题。IDE 内提供一键 CodeFix「添加 in 修饰」 |
| MA7002 | 参数类型与方法名不匹配 | `OnFooEvent` 的参数类型应是 `FooEvent`；传入其他 `IGameEvent` struct 时告警 |
| MA7003 | 无参回调所在类型应 `partial` | 无参回调仅能经生成器桥接，宿主类型必须声明 `partial` |

调级示例（工程根 `.editorconfig`）：

```ini
[*.cs]
dotnet_diagnostic.MA7000.severity = error   # 匿名订阅直接挡编译
dotnet_diagnostic.MA7001.severity = warning
```

注意：现有测试代码中存在历史 lambda 订阅写法（`Tests/EditorMode/...`），会收到 MA7000 警告——属预期，按需提取命名方法或调整严重级别。

## 源生成器：订阅胶水

对声明为 `partial` 且含 `OnXxxEvent` 方法（0 或 1 个参数）的类型，生成器产出 `<TypeName>.g.cs` 分部文件，包含成对方法：

- **带参回调** `OnXxxEvent(in XxxEvent evt)` → 方法组直连 `EventBus.Subscribe<XxxEvent>(OnXxxEvent)`；
- **无参回调** `OnXxxEvent()` → 缓存包装委托桥接为 `EventDelegate<XxxEvent>`（`??=` 惰性缓存保证 `Unsubscribe` 值等价匹配；实例回调捕获实例、静态回调为静态缓存）；
- **不合规带参回调**（缺 `in`/`ref`/`out`）→ 跳过生成并留注释（MA7001 已告警，修正签名后重新编译即自动接入）；
- 命名冲突规避：宿主已有 `SubscribeEvents` 时回退生成 `SubscribeBusEvents`/`UnsubscribeBusEvents`。

用法：

```csharp
public partial class PlayerSystem
{
    public void OnPlayerSpawnedEvent(in PlayerSpawnedEvent evt) { ... }  // 带参
    public void OnSceneLoadedEvent() { ... }                             // 无参

    private void OnEnable()  => SubscribeEvents();
    private void OnDisable() => UnsubscribeEvents();
}
```

生成代码形如（`EventBusSubscriptions_<全限定名>.g.cs`）：

```csharp
// <auto-generated/> 由 EventBusAnalyzer Source Generator 生成——请勿手工修改。
public partial class PlayerSystem
{
    private global::Moirai.Atropos.EventDelegate<Game.SceneLoadedEvent> __eventBusHandler_sceneloadevent_OnSceneLoadedEvent = null!;

    public void SubscribeEvents()
    {
        global::Moirai.Atropos.EventBus.Subscribe<Game.PlayerSpawnedEvent>(OnPlayerSpawnedEvent);
        __eventBusHandler_sceneloadevent_OnSceneLoadedEvent ??= (in Game.SceneLoadedEvent _) => OnSceneLoadedEvent();
        global::Moirai.Atropos.EventBus.Subscribe(__eventBusHandler_sceneloadevent_OnSceneLoadedEvent);
    }

    public void UnsubscribeEvents() { /* 成对退订 */ }
}
```

## 边界与限制

- 生成器仅处理**非泛型、声明为 `partial`** 的宿主类型；无参回调的事件类型须与本回调声明在同一编译（asmdef）内（按名解析）。
- `ref`/`out` 参数的事件回调与 `EventDelegate<T>(in T)` 根本不兼容（无法订阅），生成器跳过并由 MA7001 提示。
- 结构体宿主上的无参回调捕获的是订阅瞬间的副本，退订仍值等价命中，但订阅后对结构体的修改不会反映到回调——建议宿主用 class。
- 生成代码文件以 `<auto-generated/>` 头标注，本分析器自身豁免对它的检查。
- 诊断均默认 Warning；Unity Console 不显示 IDE 级 CodeFix，一键修复需在 Visual Studio / Rider 中使用。

## 构建

```bash
# 源码目录内
cd Packages/com.moirai.framework/SourceGenerators/Source~/EventBusAnalyzer
dotnet build -c Release        # DLL 直出 SourceGenerators/EventBusAnalyzer.dll

# 自检（诊断计数 + 生成代码可编译性验证）
cd ../EventBusAnalyzer.Probe
dotnet run -c Release
```

版本锁定：`Microsoft.CodeAnalysis.CSharp 4.3.0`（Unity 6000 内置 Roslyn 版本），目标框架 `netstandard2.0`，与其他 `Source~/` 项目同口径。
