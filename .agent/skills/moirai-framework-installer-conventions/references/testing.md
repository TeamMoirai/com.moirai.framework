# 测试与验证分层（本包）

## 装配事实

本包没有测试装配：无 `Tests/`、无 asmdef、无 PlayMode。没有 CI 工作流。

## 替代判据

| 层 | 能给什么 | 不能给什么 |
|---|---|---|
| 编译门 | 宿主编辑器程序集是否 0 error | 安装流程 |
| 静态判据 | 路径/常量/守卫/meta | Package Manager 行为 |
| 人工点验 | 打开窗口、检查环境、装包、导模板 | 回归证明 |

## 写什么、不写什么

| 写 | 不写 |
|---|---|
| 状态 JSON 解析/兼容（若未来建测试） | 真实 Package Manager 网络行为 |
| 作用域合并/模板占位判断的纯逻辑 | 宿主工程最终设置 |

## 改动的验证清单

| 改动 | 最低验证 |
|---|---|
| 只改文档 | 指针与符号自查 |
| 改窗口/流程 | 编译门 + 打开窗口点验 |
| 改 manifest/ProjectSettings 写入 | 编译门 + 在测试工程点验 + 备份 |
| 改模板导入 | 编译门 + 空工程导入点验 |

## 判绿与出口

- 编译门 0 error；无测试装配，人工点验单列，不写成回归。
- 真实安装流程未在干净工程跑过时写“未取证”。
